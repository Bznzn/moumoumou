# 牛马冲冲冲

macOS Electron 小悬浮窗，根据月薪与计划作息展示今日及本月收入。默认人民币，按计划工时估算，不记录实际出勤或计算税费。

## 使用

将安装包中的「牛马冲冲冲」拖入应用程序。首次填写月薪、工作日或大小周及上下班、午休时间。以后登录 Mac 自动出现，菜单栏「¥」提供设置、收入概览、显示/隐藏和退出。

大小周以指定周一及大/小周为参考连续轮换；点击排班日历可以单独修改休息或补班。修改某月日期会改变该月计划总工时，因此会重新折算整个月的每秒收入和每日金额。调薪或修改常规作息默认下月生效，选择本月时保存前会提示重算。

午休暂停、下班保留成果。悬停时窗口会变淡。金额只滚动变化数位，每赚满 ¥100 轻微微光，可改为 ¥10 或关闭，遵循系统减少动态效果设置。

应用默认使用兼容显示，保留收入悬浮窗、点击穿透和悬停变淡。与 Codex mini 同时使用时，可以在「设置 → 悬浮窗与启动 → 浮窗位置与大小」移动和缩放收入浮窗，调整即时生效并自动保存。需要直接拖动、边缘拉伸或全屏自动变淡时，可在「设置 → 悬浮窗与启动」启用原生交互并保存。

0.1.5 修复原生辅助进程断开时的 write EPIPE 崩溃；断线后停止输入服务并显示重新连接提示。

0.1.4：靠近边缘时显示 ↔ / ↕ / 斜向方向提示并微亮对应边缘，系统箭头保持不变。移出后消失，提示自身不接收点击。边缘热区随窗口尺寸缩放。

0.1.1：可拖动悬浮窗四边或四角等比拉伸，尺寸为默认的80%–200%，金额和文字一起缩放并记住大小；不接入触控板捏合手势。内部拖动移动位置，单击仍穿透。边缘拉伸依赖同一原生辅助程序，更新后系统可能要求重新确认辅助功能权限。

应用新图标由内置 image_gen 生成：可爱动漫风，左牛右马争抢中央金币。原始图像为 `assets/icon-cow-horse.png`，完整提示词为 `assets/icon-prompt.txt`。

## 点击穿透和三指拖动

这组交互使用本地原生辅助程序：在悬浮窗范围内区分单击与拖动。单击在释放后交给后方窗口，拖动则移动悬浮窗；不需要解锁按钮。单击会有等待释放的时序差异，不能当作完整透明的输入层处理所有按住交互。

需要用户自行决定是否为设置页面「授权应用路径」列出的应用（正式包为「牛马冲冲冲.app」）开启 macOS「隐私与安全性 → 辅助功能」权限，再点「重新连接」。系统三指拖动须在「辅助功能 → 指针控制 → 触控板选项」中开启。

辅助程序不监听键盘文本、不联网；仅处理在悬浮窗范围内开始的鼠标输入。拒绝权限时仍可显示和穿透，但直接拖动不可用，设置会明确提示。退出程序将终止辅助进程，可随时在系统设置撤销权限。

全屏识别使用公开系统展示接口与前台窗口边界补充检测；占满屏幕且隐藏系统栏的普通窗口也可能按全屏避让，以不打扰为优先。

0.1.3 修复刘海屏全屏窗口顶部菜单带与安全区高度不一致时的漏判。不透明度越低越透明；全屏与全屏悬停设置在保存后分别应用。

## 本地数据

为保留改名前的数据，配置仍保存于 `~/Library/Application Support/秒薪/config.json`，包含工资与排班版本、日期调整和窗口偏好。文件仅当前用户可读写，有最后一次有效备份。配置损坏时提示恢复，不默默清空。没有账户、云同步或在线节假日来源。

## 开发与检查

要求 macOS 13+、Apple Silicon、Node 22.12+ 和 Xcode 命令行工具。当前目标为本机 arm64；未提供跨平台版本。

```sh
npm install
node node_modules/electron/install.js
npm --prefix prototypes/window-interactions install
node prototypes/window-interactions/node_modules/electron/install.js
npm --prefix prototypes/window-interactions run build:native
npm test
npm run typecheck
npm run dev
```

构建安装包：`npm run dist:mac`。集成测试：`npm run test:e2e`（默认测试已经构建的 `release/mac-arm64/牛马冲冲冲.app`）。可用 `SALARY_FLOAT_EXECUTABLE` 指定其他构建产物。

集成测试只用临时数据目录，不注册登录项，不显示窗口，也不启动原生输入服务；这不能代替真实系统手势、休眠恢复和多显示器验收。

此版本用于本机使用，使用本机临时签名，未购买开发者签名、未公证，也未接入自动更新或对外发行渠道。原生验证实验单独保留于 `prototypes/window-interactions/`，不混同于正式产品。
